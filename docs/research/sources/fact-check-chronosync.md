## Other errors noticed

- **The manual URL cited is stale**: `CS_Manual.pdf` is the legacy ChronoSync 4.x manual (© 2002–2018; e.g., it still describes "eleven synchronization operations" with Bootable/Bootable Mirror variants and pre-v10 behavior). Econ's current documentation is the in-app help and the Guides/FAQ pages; version-12 features (Data Volume Backup, two-pass sync, etc.) are not in this PDF.
- **Econ's own site is internally inconsistent about the bundle discount**: the homepage/ChronoAgent pricing says bundle $59.98 = "SAVE $10!", but a ChronoSync overview popup says "Bundle & Save $5!" ($49.99 + $19.99 − $59.98 = $9.99, so "$10" is the correct figure; "$5" is wrong).
- **Stale FAQ text**: the ChronoSync FAQ still says "ChronoSync 4.8 will be able to create bootable backups of APFS volumes… when High Sierra is released later this fall" — a sentence left over from 2017.
- **Express 1.4.1 date mismatch**: Econ's release notes date 1.4.1 as November 7, 2024, while the App Store version history displays "01/08/2025".
- The Macworld article is titled "…2025" but metadata shows it was last updated 2026-08-05; its Carbon Copy Cloner cons still cite "Problems creating a bootable drive on M-series Macs," similar in spirit to (and consistent with) the Apple Silicon caveats in claim 5.
