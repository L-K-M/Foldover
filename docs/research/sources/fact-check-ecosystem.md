## Other errors noticed

- **pavao license change**: pavao ≤0.2.x was GPL-3.0; it was relicensed to MIT starting with 0.3.0 (2026-09-01). Worth noting if quoting older versions.
- **bisync `--max-delete` vs global `--max-delete`**: bisync's flag takes a percentage (0–100, default 50); the identically named global rclone flag takes an absolute count (default -1). Easy to conflate.
- **FreeFileSync binaries ≠ plain GPLv3**: the source is GPL-3.0, but the License.txt shipped with the distributed binaries adds "private use only / commercial use requires Business Edition" terms — a GPL §7 additional-terms restriction Debian has questioned. Calling FFS simply "GPL-3.0" is accurate for the source but glosses over the binary's extra restrictions.
- **Unison upstream caveats (2.54.0 notes)**: drops wire-protocol compat with <2.52.0; warns external-rsync support and even the GUI may be dropped suddenly; Mac GUI is explicitly unverified. Relevant context around the Gatekeeper-disabled cask.
- **iroh-ffi scope**: first-party bindings mirror the stabilized iroh 1.0 surface only — iroh-blobs/iroh-docs/iroh-gossip are out of scope for the FFI bindings.
